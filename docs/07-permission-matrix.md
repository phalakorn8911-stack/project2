# 🔐 Permission Matrix & RBAC

## Smart Army Vehicle Maintenance Dashboard

---

## 1. Roles (บทบาทในระบบ)
1. **Admin** - ผู้ดูแลระบบ
2. **เจ้าหน้าที่ยานยนต์** - ผู้ดูแลทะเบียนรถและรอบการซ่อม
3. **พลขับ/ผู้ใช้งานรถ** - ผู้ใช้รถจริง
4. **ช่างซ่อม** - ผู้ปฏิบัติงานซ่อม
5. **หัวหน้าช่าง** - ผู้คุมงานซ่อม อนุมัติ และตรวจคุณภาพ
6. **เจ้าหน้าที่คลังอะไหล่** - ผู้ดูแลสต็อก
7. **ผู้บังคับบัญชา/ผู้บริหาร** - ผู้ดูภาพรวม

## 3. Implementation Approach (การนำไปใช้งานจริง)

1. **Middleware (`middleware.ts`)**
   - ตรวจสอบ Session ว่า Login หรือยัง
   - ป้องกันการเข้าถึง Route ที่ไม่อนุญาต เช่น `/users` ให้เข้าได้เฉพาะ Role = `Admin`
2. **Server Actions (`lib/auth.ts` + `actions/*`)**
   - ตรวจสอบ Session และ Role ก่อนทำ Database Mutation เสมอ ป้องกันการยิง API ตรง
3. **UI Level (`components/`)**
   - ซ่อน/แสดง ปุ่มและเมนู ตาม Role ของผู้ใช้งานที่ได้จาก Session
